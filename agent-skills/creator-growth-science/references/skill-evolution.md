# Skill evolution governance

Never modify a production Skill from one post or comment. Every proposal must show the current version and baseline, evidence with sample size and dates, exact proposed rule, expected benefit and regression risk, affected content, rollback plan, replay against at least five prior topics, explicit user approval, and post-change comparison.

Reject changes explained by topic, season, paid reach, account growth, or post age. Keep experimental and production Skill versions separate.
